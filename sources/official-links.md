# 出典・公式リンク台帳

最終更新：2026-10-11

## 管理ルール
- 原則として広島県教育委員会、広島県、各高校等の一次資料を優先する。
- 各資料に「資料名／対象年度／発行元／公式URL／確認日／確認状況／対応データ」を記録する。
- 未検証のURL・年度・出典は推測せず「未確認」と記す。
- 塾内資料・育伸社データ・独自集計は公式資料とは別に区別する。
- 公式ページとPDF直リンクが両方ある場合は両方保存する。公開年度が変わった場合は旧リンクも履歴として保持する。
